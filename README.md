# ig-psic-isaaccalderond

Puente Broca ↔ Claude para el Instagram de práctica `@psic.isaaccalderond`.

## Quién hace qué
- **Broca** escribe el brief en `briefs/` (copy + dirección de arte).
- **Claude Code** (este repo) genera PNG en `out/`.
- **Isaac** aprueba y publica o programa en Meta Business Suite.

## Primera prueba
```bash
git clone https://github.com/isaaccalderond888/ig-psic-isaaccalderond.git
cd ig-psic-isaaccalderond
claude
```
Luego: `Lee briefs/2026-09-18-entrevista-20min.md y genera el carrusel en out/2026-09-18/`
